# Yvenist 🎉

### The All-in-One Marketplace for Events & Parties

> Connecting people who want to celebrate with the best venues and service providers — all in one place.

---

## 📱 About

**Yvenist** is an innovative, full-featured marketplace dedicated exclusively to the events and parties sector. Strongly inspired by Airbnb's business model, it's not just a listing catalog — it's a **digital ecosystem** that centralizes the entire event planning journey: discovery, negotiation, payment, and management.

### 🎯 The Problem It Solves

Organizing an event (a wedding, a birthday party, or a corporate gathering) traditionally involves chaos: searching for venues on Google, requesting quotes via WhatsApp, and finding suppliers in a fragmented, unreliable way.

**Yvenist** solves this by acting as the unified, trusted bridge — bringing the events market into the modern digital era.

---

## ✨ Key Features

### 🔄 Dual-Mode Architecture (Client & Supplier)

The platform's greatest architectural feature: it hosts **two universes in a single app**, allowing users to switch between modes through an intelligent toggle on the Profile screen.

#### 👤 Client Mode — For the Event Organizer
- **Rich Discovery Feed** — Explore trending venues, attractions, and services in your area
- **Party Builder** — A dedicated space to plan the event step by step, manage confirmed events, track quotes, and save favorite suppliers
- **Secure Payments** — Centralized payment system with transparent financial history
- **Real Reviews & In-App Chat** — Verified user ratings and direct communication with suppliers

#### 🏪 Supplier Mode — For the Business Partner
- **Structured Onboarding with Fraud Prevention** — Rigorous registration flow requiring identity verification (CPF/CNPJ), infrastructure details, cancellation policies, and mandatory photo uploads — all reviewed through an approval pipeline
- **Professional Dashboard** — Once approved, users get a control panel showing financial balance, average rating, new requests, and availability management
- **Promotion Tools** — Features to boost listings and create discount campaigns

## 🏗️ Architecture

Built with **Clean Architecture** principles:
- Clear separation of layers (Presentation, Domain, Data)
- Reusable components and structured navigation
- Modular listing system — supports Venues, Decoration, Catering, Entertainment, and more
- LGPD-ready with Two-Factor Authentication (2FA) and connected device management

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/KevenSanchesG/Yvenist.git

# Navigate to project directory
cd Yvenist

# Install dependencies
flutter pub get

# Run the app
flutter run
```

> **Note:** Firebase configuration required. Create your `google-services.json` and `GoogleService-Info.plist` files and add them to the appropriate directories.
